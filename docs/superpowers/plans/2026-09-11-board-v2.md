# Board v2 Implementation Plan

## Summary
Upgrade `/board` from flat list to grouped game-instance view with session duration, player count, and timestamp. Add optional compact mode.

## Current Behavior
- Flat list: `**User** 🎮 GameName (type) [join](url)`
- Splits at 15 rows per embed
- Footer: quiet mode + TikTok watch
- No grouping, no duration, no player count, no timestamp

## Target Behavior

**Default (verbose):**
```
╔══════════════════════════════════════╗
║  ● Status Board                      ║
╠══════════════════════════════════════╣
║  Jailbreak (3/32) Public            ║

**Compact (`/board compact`):**

Blox Fruits: Dave
Offline: Eve, Frank
```

## Files to Modify

### 1. `services/discord.js` — `buildBoardLines()`
**Current:** Flat array of markdown strings
**New:** Returns `{ lines, inGame, idle, groups }` where `groups` is structured data for grouping

Changes:
- Rewrite `buildBoardLines()` to return grouped data
- Add `buildBoardLinesCompact()` for compact mode
- Group users by `gameName + serverType` (same game same type = same group)
- Within each group, show session duration: `timeSince(s.sessionStart)` using existing `formatUptime` logic
- Show player count: `serverPlayerCount/maxLength` when available from snapshot
- Sort: in-game groups alphabetical by game name, then users alphabetical within group, offline last
- Keep existing: join link when available, no emoji, `×` for offline marker

### 2. `bot/commands.js` — Add compact option
**Current:** `.setName('board').setDescription('...')` (no options)
**New:** Add `.addBooleanOption(o => o.setName('compact').setDescription('Short single-line view'))`

### 3. `bot/index.js` — `board()` handler
**Current:** Lines 548-569. Calls `buildBoardLines()`, chunks at 15, builds embeds
**New:**
- Read `compact` option from interaction
- If compact: call `buildBoardLinesCompact()`, single embed, no chunking
- If verbose: call `buildBoardLines()` (new grouped version), chunk at 8 groups per embed (not 15 lines)
- Add timestamp: `footer.push('Last updated: ' + relativeTime(Date.now()))`
- Use existing `formatUptime` or inline `timeSince` for relative timestamps

### 4. `test/run-checks.js` — Update board test
**Current:** Block 9c tests `buildBoardLines` with flat output assertions
**New:**
- Update board snapshot to include `sessionStart` and `serverPlayerCount` fields
- Assert grouped structure: groups array, each group has gameName, players array
- Test compact mode output
- Test that offline users appear last
- Test that session duration appears in output

## Implementation Order

1. **services/discord.js** — rewrite `buildBoardLines()`, add `buildBoardLinesCompact()`
2. **bot/commands.js** — add compact option to /board
3. **bot/index.js** — update `board()` handler for grouping, compact, timestamp
4. **test/run-checks.js** — update board tests for new output
5. **Run tests** until exit 0
6. **Bump version** 2.5.3 → 2.5.4 in package.json

## Data Flow

```
board(interaction)
  → store.getUsers()           // [{ username, ... }]
  → tracker.pollOnce()         // fresh Roblox data
  → tracker.getSnapshot()      // [{ username, status, gameName, placeId, serverType, joinUrl, gameUrl, sessionStart, serverPlayerCount, ... }]
  → buildBoardLines(users, snapshotMap)  // NEW: returns { lines, groups, inGame, idle }
  → chunk groups (8 per embed)
  → build embeds with timestamp footer
```

## Edge Cases
- **No users tracked:** Show "No tracked users yet." (unchanged)
- **All offline:** Show offline section only, no game groups
- **Unknown player count:** Show `?` or omit count (e.g., `Jailbreak (Public)` instead `Jailbreak (3/32)`)
- **No sessionStart:** Show `—` instead duration
- **Many groups (20+):** Chunk at 8 groups per embed, title shows page number
- **Compact mode + many users:** Single embed, comma-separated per game, no chunking needed
